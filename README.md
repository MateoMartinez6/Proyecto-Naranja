# Citrik Studio

# Libropedia

# Nombre del proyecto: Libropedia

# Descripcion / Enunciado del proyecto: Una aplicación móvil parecida a letterbox (pueden buscarla si no la conocen) pero versión
libros/comic/manga. La idea es que se puedan descubrir libros nuevos o poder llevar un registro de
los leídos. Se podrá iniciar sesión (Inicio de sesión / registro de sesión / recuperación de contraseña).
Dentro de la aplicación aparecerá una pagina principal con novedades. Podrás ver en otra pagina las
reseñas de gente a libros y podrás crear tus propias listas de libros y agregar cualquiera de los libros
que estén en la pagina. Se podrá seleccionar un libro y darle una calificación, pulsar si el libro lo
leíste o no y poder dejar una breve reseña. Se podrá ver información del libro como una sinopsis,
autor y rating en general de la gente que lo fue calificando de 1 a 5 estrellas.
